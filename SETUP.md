# 🚀 Розгортання проекту TourAgency

Інструкція як встановити і запустити проект на будь-якому комп'ютері з нуля.

---

## Що потрібно встановити

| Програма | Версія | Посилання |
|----------|--------|-----------|
| **Node.js** | 18 або вище | https://nodejs.org |
| **MongoDB Community Server** | 6 або вище | https://www.mongodb.com/try/download/community |
| **MongoDB Compass** | будь-яка | https://www.mongodb.com/try/download/compass |
| **Git** | будь-яка | https://git-scm.com |

---

## Крок 1 — Отримай код проекту

```bash
git clone https://github.com/zmigd/Kate-tour.git
cd Kate-tour
```

---

## Крок 2 — Встанови залежності

```bash
cd backend
npm install
```

---

## Крок 3 — Створи файл налаштувань

У папці `backend/` створи файл з назвою `.env` і встав такий вміст:

```
PORT=5000
MONGO_URI=mongodb://localhost:27017/tourdb
JWT_SECRET=your_super_secret_key_change_me
JWT_EXPIRES_IN=7d
```

> ⚠️ Файл `.env` не зберігається в Git — його треба створювати вручну на кожному новому комп'ютері.

---

## Крок 4 — Запусти MongoDB

1. Відкрий **MongoDB Compass**
2. Натисни **"New Connection"**
3. У полі URI вкажи: `mongodb://localhost:27017`
4. Натисни **"Connect"**

Якщо з'єднання успішне — MongoDB працює. Можна йти далі.

---

## Крок 5 — Заповни базу даних

Виконай команду (один раз):

```bash
node seed.js
```

Скрипт автоматично створить у базі даних:
- 3 користувачі: адмін (роль `admin`), менеджер (роль `manager`), клієнт (роль `client`)
- 5 послуг, 7 країн, 7 міст, 7 готелів
- 7 готових турів з фотографіями

Після виконання в терміналі побачиш:
```
✓ MongoDB connected
✓ Collections cleared
✓ Users created
✓ Tours created (7)
🎉 Database seeded successfully!
```

> ⚠️ Скрипт **очищує** всі колекції перед заповненням. Не запускай його повторно якщо вже є власні дані.

---

## Крок 6 — Запусти сервер

```bash
npm start
```

Або в режимі розробки (автоматичний перезапуск при змінах файлів):

```bash
npm run dev
```

---

## Крок 7 — Відкрий сайт

Відкрий у браузері: **http://localhost:5000**

Тестові логіни:

| Email | Пароль | Роль |
|-------|--------|------|
| admin@tour.com | 123456 | Адмін (панель + управління користувачами) |
| manager@tour.com | 123456 | Менеджер (панель, тури, бронювання) |
| client@tour.com | 123456 | Клієнт |

# 💾 Перенос бази даних на інший комп'ютер

Якщо в базі вже є власні дані (додані тури, реальні бронювання), їх можна перенести трьома способами.

---

## Спосіб 1 — mongodump / mongorestore (термінал)

Найнадійніший спосіб. Зберігає всі дані точно.

### На СТАРОМУ комп'ютері — зробити резервну копію

```bash
mongodump --db tourdb --out C:\backup\tourdb-backup
```

Після виконання з'явиться папка `C:\backup\tourdb-backup` з усіма даними.

> Якщо команда `mongodump` не знайдена — встанови окремо:
> [mongodb.com/try/download/database-tools](https://www.mongodb.com/try/download/database-tools)

Скопіюй папку `tourdb-backup` на флешку або надішли через хмару.

### На НОВОМУ комп'ютері — відновити з копії

1. Виконай **Кроки 1–4** з інструкції вище (без seed.js)
2. Скопіюй папку `tourdb-backup` на новий комп'ютер
3. Виконай відновлення:

```bash
mongorestore --db tourdb C:\backup\tourdb-backup\tourdb
```

4. Запусти сервер: `npm start`

---

## Спосіб 2 — MongoDB Compass (без термінала)

Підходить якщо не хочеш використовувати командний рядок.

### На СТАРОМУ комп'ютері — експорт

1. Відкрий **MongoDB Compass** → підключись
2. Відкрий базу `tourdb`
3. Для **кожної** колекції (tours, users, bookings, countries, cities, hotels, services):
   - Клікни на колекцію
   - Натисни кнопку **"Export Data"**
   - Вибери формат **JSON**
   - Збережи файл (напр. `tours.json`, `users.json` тощо)
4. Надішли всі `.json` файли на новий комп'ютер

### На НОВОМУ комп'ютері — імпорт

1. Виконай **Кроки 1–4** з інструкції вище (без seed.js)
2. Відкрий **MongoDB Compass** → підключись
3. Натисни **"+"** → вкажи назву бази: `tourdb` → **"Create Database"**
4. Для **кожної** колекції:
   - Натисни **"+"** поруч з базою
   - Вкажи назву колекції (напр. `tours`)
   - Натисни **"Add Data"** → **"Import JSON or CSV file"**
   - Вибери відповідний `.json` файл
5. Повтори для всіх 7 колекцій
6. Запусти сервер: `npm start`

---

## Спосіб 3 — Просто запустити seed.js заново (якщо своїх даних немає)

Якщо власних турів та бронювань немає і потрібні лише тестові дані — просто виконай:

```bash
node seed.js
```

Це найшвидший спосіб розгортання на новому комп'ютері.

## Типові помилки

**❌ `Cannot connect to MongoDB`**
```
Причина:  MongoDB не запущена
Рішення:  Відкрий MongoDB Compass і підключись до localhost:27017
```

**❌ `Error: listen EADDRINUSE :::5000`**
```
Причина:  Порт 5000 вже зайнятий (сервер вже запущений)
Рішення:  Закрий попередній термінал або зміни PORT=5001 у файлі .env
```

**❌ `Cannot find module`**
```
Причина:  Залежності не встановлено
Рішення:  cd backend && npm install
```

**❌ `Seed failed: Authentication failed`**
```
Причина:  MongoDB потребує пароль (не стандартна конфігурація)
Рішення:  Перевір MONGO_URI у файлі .env
```

**❌ `Not authorized` / `JWT malformed`**
```
Причина:  Токен застарів або відсутній
Рішення:  Вийди з акаунту та увійди знову
```

**❌ Сторінка не завантажується після `npm start`**
```
Причина:  Сервер ще стартує або є помилка в консолі
Рішення:  Почекай 2–3 секунди, перевір термінал на помилки
```
